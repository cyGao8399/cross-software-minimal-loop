# 客户需求知识卡片

> 这是手工审核后的可读知识卡片；自动生成版本见 `客户需求知识卡片-自动生成.md`。

## 客户背景

远岑咖啡（虚构）希望用一个轻量流程统一收集客户需求，减少聊天、邮件和多份表格之间的信息漂移。

## 关键规则

1. 客户资料进入飞书 Base 后，必须有来源、负责人、状态、优先级和截止日期。
2. 状态进入“待验收”且提醒字段为“否”时，只向负责人发送一次提醒。
3. 需求范围先限定为测试数据，验证正常触发、防重复和不应触发后再扩大。
4. 知识卡片只保留业务背景、流程规则和验收标准，不保存个人敏感信息。

## 可复用决策

先统一数据结构，再拆分任务；先固定验收证据，再讨论扩展功能。这样可以把“客户说了什么”转化为“团队下一步做什么”和“如何证明已经完成”。

## 来源与去向

- 来源：`data/customer_intake.csv`（来自飞书 Base 的脱敏导出示例）。
- 去向：任务台账、交付清单、教程脚本和开源仓库。
