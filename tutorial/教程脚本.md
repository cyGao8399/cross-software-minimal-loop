# 跨软件最小闭环教程脚本

## 片头

本教程演示一条最小闭环：从飞书收集客户资料，到本地形成知识卡片、拆分任务、跟踪交付、生成教程，最后发布可复现的开源成果。示例数据全部为虚构内容。

## 第一段：收集资料

打开飞书客户跟踪 Base，确认每条记录至少有客户、需求、来源、负责人、状态、优先级和截止日期。导出脱敏 CSV，放入 `data/customer_intake.csv`。飞书负责业务数据和权限，不保存本地脚本凭据。

## 第二段：形成知识库

在项目目录运行：

```powershell
pwsh -NoProfile -File .\scripts\build-loop.ps1
```

脚本把每条记录转换为 Markdown 知识卡片，并保留记录 ID，便于从知识结论回溯原始需求。

## 第三段：拆分任务与跟踪交付

查看 `tasks/task_ledger.csv`，每条需求对应一个任务 ID、负责人、截止日期和完成标准。再打开 `delivery/交付清单.md`，确认每项交付物有接收方和验收方法。

## 第四段：录制教程

教程脚本和视频都只展示虚构数据。录制时不要展示真实客户姓名、手机号、令牌或私有链接；视频生成后先播放检查，再加入 Git。

## 第五段：发布开源成果

提交前查看 diff、运行敏感信息扫描，只把脱敏文档、脚本、样例 CSV 和教程视频推送到公开仓库。公开仓库不代表把飞书 Base 改为公开，两个权限边界必须分开。

## 片尾验收

打开 `evidence/验收证据.md`，逐条核对输入、输出、权限边界和验证结果；再从 GitHub 临时克隆并重新运行脚本，确认闭环可复现。
