本教程演示一条跨软件最小闭环，目标是把客户资料变成知识、任务、交付、教程和开源成果。示例中的客户和数据全部是虚构内容。
第一步，在飞书客户跟踪多维表格中收集客户、需求、来源、负责人、状态、优先级和截止日期。导出前确认只包含脱敏字段。
第二步，把 CSV 放入项目的数据目录，用 PowerShell 七运行 build-loop 脚本。脚本会生成可追溯的 Markdown 知识卡片和任务台账，记录 ID 在各个产物之间保持一致。
第三步，根据任务台账跟踪负责人、截止日期和完成标准，再用交付清单登记接收方和验收方法。
第四步，在 Typora 中打开教程脚本进行阅读和预览，再用本地中文语音与 ffmpeg 生成教程视频。录制时不要展示真实客户姓名、令牌或私有链接。
第五步，提交前检查 Git diff、空白字符和敏感信息，只把脱敏的虚构资料、脚本、文档和教程视频发布到公开 GitHub 仓库。
最后，从公开仓库重新克隆并运行脚本，确认输入、输出、权限边界和验证证据都能复现。这样才算完成跨软件最小闭环。
